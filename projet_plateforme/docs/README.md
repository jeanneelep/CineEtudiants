## 🚀 Quick Start

This is a **Student Project** for a video platform where:
- 📹 Students upload short films
- 👥 Users watch, like, and comment
- ⚙️ Admins moderate content

**Tech Stack**: Node.js + Express + PostgreSQL + React + Vite

**Status**: Architecture & Planning phase
